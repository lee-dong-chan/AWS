# DML

- Data Manipulation language
- 데이터를 직접적으로 다루는 언어이다.

## insert

```sql
INSERT INTO test VALUES(1,'2024-04-12 09:00:00','name','age',' nick');
```

```sql
INSERT INTO test(id,name,nick) VALUES(1,'name',' nick');
```

## update

```sql
UPDATE test SET creared_at='2024-04-12 09:12:00' WHERE id='2';
```

## select

```sql
select*from test;
+----+---------------------+--------+------+-------------+
| id | creared_at          | name   | age  | nick        |
+----+---------------------+--------+------+-------------+
|  2 | 2024-04-12 09:12:00 | 이름   | NULL | 닉네임      |
|  3 | NULL                | 이름   | NULL | 닉네임1     |
|  4 | NULL                | 이름   | NULL | 1닉네임1    |
|  5 | NULL                | 이름   | NULL | 1닉네임2    |
+----+---------------------+--------+------+-------------+
SELECT*FROM test WHERE nick LIKE '닉%';
+----+---------------------+--------+------+------------+
| id | creared_at          | name   | age  | nick       |
+----+---------------------+--------+------+------------+
|  2 | 2024-04-12 09:12:00 | 이름   | NULL | 닉네임     |
|  3 | NULL                | 이름   | NULL | 닉네임1    |
+----+---------------------+--------+------+------------+
SELECT*FROM test WHERE nick LIKE '%닉%'
+----+---------------------+--------+------+-------------+
| id | creared_at          | name   | age  | nick        |
+----+---------------------+--------+------+-------------+
|  2 | 2024-04-12 09:12:00 | 이름   | NULL | 닉네임      |
|  3 | NULL                | 이름   | NULL | 닉네임1     |
|  4 | NULL                | 이름   | NULL | 1닉네임1    |
|  5 | NULL                | 이름   | NULL | 1닉네임2    |
+----+---------------------+--------+------+-------------+
SELECT*FROM test WHERE nick LIKE '닉__';
+----+---------------------+--------+------+-----------+
| id | creared_at          | name   | age  | nick      |
+----+---------------------+--------+------+-----------+
|  2 | 2024-04-12 09:12:00 | 이름   | NULL | 닉네임    |
+----+---------------------+--------+------+-----------+
```

- %의 경우 몇글자들 상관 없다.
- \_의 경우 글자 하나를 뜻한다.

- DML에 포함하지 않고 DQL, Data Query Language에 포함시키는 경우도 있다.

# PRIMARY KEY

- 기본적인
- 데이터를 다룰 떄 -> 검색하거나? 정렬하거나?

```sql
CREATE TABLE aws_student(
    id TINYINT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(5) NOT NULL,
    age TINYINT UNSIGNED NOT NULL,
    birth VARCHAR(5),
    adress VARCHAR(20) NOT NULL,
    phone VARCHAR(13) NOT NULL UNIQUE,
    gender ENUM ('M','F') NOT NULL,
    registed_at DATETIME DEFAULT NOW()
);
```

## CONSTRAINT

- 큐칙을 정할수 있는 테이블

```sql
CREATE TABLE aws_students(
    id TINYINT UNSIGNED  AUTO_INCREMENT,
    name VARCHAR(5) NOT NULL,
    age TINYINT UNSIGNED NOT NULL,
    birth VARCHAR(5),
    adress VARCHAR(20) NOT NULL,
    phone VARCHAR(13) NOT NULL UNIQUE,
    gender ENUM ('M','F') NOT NULL,
    nick VARCHAR(10) UNIQUE,
    registed_at DATETIME DEFAULT NOW()
    CONSTRAINT aws_student_pk PRIMARY KEY(id,nick)
);
```
